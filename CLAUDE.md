# CLAUDE.md

Guidance for AI assistants working in this repository (`ocd-jacky-777`, the **Jackie** app).

## What this repo is

Three things live side by side:

1. **Jackie web app** — Vite + React 18 + TypeScript + Tailwind + shadcn-ui, built on **Lovable** (lovable.dev) with **Supabase** (Postgres/RLS/edge functions) as the backend. Root of the repo.
2. **Embedded subsystems** — the whole "PC" OS as a prebuilt static bundle (`public/pc-os/`, iframed at `/pc`) and ~91 pages imported from the **Eru** Base44 app (`src/eru/`, mounted lazily).
3. **`Jackie/`** — a standalone, stdlib-only **Python local assistant core** (memory, resonance, security scanner, dispatcher) plus the design/doctrine docs. It is independent of the web app.

Fleet context (PC, Eru, Jackie, Empath) and the parity work are described in `FLEET_PARITY_PLAN.md` and `PARITY_MATRIX.md`. This repo is the Lovable-platform member of the fleet.

## Commands

Web app (npm or bun; both lockfiles are committed, `package-lock.json` is the primary):

```sh
npm i
npm run dev          # vite dev server on port 8080 (host "::")
npm run build        # production build; build:dev for development mode
npm run lint         # eslint .
npm test             # vitest run (jsdom, globals, setup: src/test/setup.ts)
npm run test:watch
```

Python core (run from `Jackie/`, no dependencies):

```sh
cd Jackie
python3 jackie_assistant.py                 # interactive
python3 jackie_assistant.py "a question"    # one shot
python3 -m unittest discover -s tests
```

Model downloader (runs on a user's PC, not in the app; needs `huggingface_hub`):

```sh
python scripts/download_models.py --plan --phase 1
```

## Key architecture notes

- **Providers/auth**: `App.tsx` nests QueryClient → Theme → Auth → I18n → Tooltip → Router. Unauthenticated users hitting a protected route get `<Auth />`. The `?sandbox=true` flag is honoured **only** on `/sandbox` and never unlocks protected routes or AI edge functions — keep it that way.
- **AI calls** go through Supabase edge functions (`jackie-orchestrate` and per-provider functions); the client side lives in `src/lib/jackie-orchestrator.ts`, `jackie-providers.ts`, `jackie-provider-stream.ts`. Do not call providers directly from the browser with secrets.
- **Eru import** (`src/eru/`): routes come from `routes.generated.ts` and are lazy-loaded behind `EruRouter`, each wrapped in `EruPageShell` with an EXPERIMENTAL banner and `EruErrorBoundary`. Eru code is largely `.jsx` and talks to Base44 through a bridge; treat it as imported code — avoid broad refactors/lint-driven rewrites there.
- **PC embed**: `src/pages/PCDesktop.tsx` iframes `/pc-os/index.html?pc=full`; deep links use `/pc?app=<id>`. The service worker (`vite.config.ts`, VitePWA) excludes `/pc-os/**` from precache/navigation fallback. Update the bundle by rebuilding the PC repo and re-copying, per `docs/PC_EMBED.md`.
- **PWA**: configured in `vite.config.ts`; `navigateFallbackDenylist` covers `/~oauth`, `/api`, `/functions`. Preserve these when editing.
- **Supabase types**: `src/integrations/supabase/types.ts` and `client.ts` are generated by Lovable — don't hand-edit. Schema changes = new migration file in `supabase/migrations/`; use RLS, and role checks via the `has_role` function / `user_roles` table (never trust client-supplied roles).

## `Jackie/` Python core

Modules in `Jackie/core/`: `config`, `dispatcher`, `memory` (tiered, SQLite in `Jackie/memory/*.db` — gitignored local state), `resonance`, `security` (pattern risk scanner that **redacts** secrets it finds). Entry point `jackie_assistant.py`; tests in `Jackie/tests/` (unittest). Prompts in `Jackie/prompts/`; durable notes in `Jackie/knowledge/`.

Governing docs (read before changing behavior): `CORE_IDENTITY.md`, `BEHAVIOR_RULES.md`, `SECURITY_PRINCIPLES.md`, `MEMORY_MODEL.md`, `RESONANCE_MODEL.md`, `ARCHITECTURE.md`, `ROADMAP.md`. Design principle: *low complexity surface area, high capability core.* Keep it standard-library-only, offline, and secrets out of logs.

## Conventions

- TypeScript + functional React components, Tailwind utility classes, shadcn/Radix primitives in `components/ui` (add via shadcn conventions; `components.json` is present).
- Use the `@/` import alias; prefer `@tanstack/react-query` for server state and `react-hook-form` for forms.
- Lazy-load heavy pages (`React.lazy`) as done for `ModelQueue` and Eru.
- Add new routes in `App.tsx`; wrap in `ProtectedRoute` unless intentionally public; add a sidebar entry in `components/SidebarNav.tsx` when user-facing.
- Tests: Vitest + Testing Library under `src/test/`; Python tests under `Jackie/tests/`. Run both suites you touched before committing.
- Docs/notes about decisions go in `Jackie/knowledge/notes/` (dated `YYYY-MM-DD_topic.md`) or `docs/`.
- Security posture matters: validate inputs in edge functions, keep roles server-side, compare methods/origins carefully, don't reveal whether reads are open when they require sign-in (recent commits hardened these).
- `.env` is committed and holds only Supabase **public/publishable** values (`VITE_SUPABASE_*`). Never add private keys or service-role secrets to it or to client code.
- Lovable commits to this repo automatically; keep changes small and mergeable so they don't conflict with Lovable edits.

## Git workflow
